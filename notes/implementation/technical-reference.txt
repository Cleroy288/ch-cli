SEMANTIC INDEXER - TECHNICAL REFERENCE

This is a quick reference for the technical details of integrating Tree-sitter,
Tantivy, and Stack-graphs.

================================================================================
1. TREE-SITTER QUICK START
================================================================================

Basic Setup:
```rust
use tree_sitter::{Parser, Language, Query};

// Initialize parser
let mut parser = Parser::new();
let language: Language = tree_sitter_rust::LANGUAGE.into();
parser.set_language(&language)?;

// Parse code
let source_code = std::fs::read_to_string("file.rs")?;
let tree = parser.parse(&source_code, None).unwrap();
let root_node = tree.root_node();
```

Writing Queries (queries/rust.scm):
```scheme
; Function definitions
(function_item
  name: (identifier) @function.name
  parameters: (parameters) @function.params
  body: (block) @function.body)

; Struct definitions
(struct_item
  name: (type_identifier) @struct.name
  body: (field_declaration_list)? @struct.body)

; Impl blocks
(impl_item
  type: (type_identifier) @impl.type
  body: (declaration_list) @impl.body)
```

Running Queries:
```rust
let query = Query::new(&language, query_source)?;
let mut cursor = QueryCursor::new();
let matches = cursor.matches(&query, root_node, source_code.as_bytes());

for match_ in matches {
    for capture in match_.captures {
        let node = capture.node;
        let text = &source_code[node.byte_range()];
        let location = (node.start_position().row, node.start_position().column);
        // Process symbol...
    }
}
```

Key Tree-sitter Concepts:
- Node: Represents AST element (has type, range, children)
- Tree: Complete AST for a file
- Query: S-expression pattern matching
- Cursor: Iterator for traversing nodes/matches
- Point: Line/column position (0-indexed)

Performance Tips:
- Reuse Parser instances across files
- Use tree.edit() for incremental parsing
- Cache compiled queries
- Process files in parallel with rayon

================================================================================
2. TANTIVY INTEGRATION
================================================================================

Schema Definition:
```rust
use tantivy::schema::*;
use tantivy::{Index, IndexWriter, ReloadPolicy};

// Define schema
let mut schema_builder = Schema::builder();
schema_builder.add_text_field("symbol_name", TEXT | STORED);
schema_builder.add_text_field("kind", STRING | STORED);
schema_builder.add_text_field("file_path", STRING | STORED);
schema_builder.add_u64_field("line", STORED | INDEXED);
schema_builder.add_u64_field("column", STORED | INDEXED);
schema_builder.add_text_field("signature", TEXT | STORED);
schema_builder.add_text_field("fqn", TEXT | STORED); // Fully qualified name
let schema = schema_builder.build();
```

Creating Index:
```rust
// Create index directory
let index_path = Path::new(".ch-cli-index");
std::fs::create_dir_all(index_path)?;

// Create index
let index = Index::create_in_dir(index_path, schema.clone())?;
let mut index_writer = index.writer(50_000_000)?; // 50MB heap
```

Indexing Documents:
```rust
// Get field handles
let symbol_name = schema.get_field("symbol_name").unwrap();
let kind = schema.get_field("kind").unwrap();
let file_path = schema.get_field("file_path").unwrap();
let line = schema.get_field("line").unwrap();

// Add documents in batch
for symbol in symbols {
    let mut doc = Document::new();
    doc.add_text(symbol_name, &symbol.name);
    doc.add_text(kind, &symbol.kind.to_string());
    doc.add_text(file_path, symbol.location.file.to_str().unwrap());
    doc.add_u64(line, symbol.location.line as u64);
    index_writer.add_document(doc)?;
}

// Commit
index_writer.commit()?;
```

Searching:
```rust
use tantivy::query::QueryParser;

// Create reader
let reader = index.reader_builder()
    .reload_policy(ReloadPolicy::OnCommitWithDelay)
    .try_into()?;

// Build query
let searcher = reader.searcher();
let query_parser = QueryParser::for_index(&index, vec![symbol_name]);
let query = query_parser.parse_query("my_function")?;

// Execute search
let top_docs = searcher.search(&query, &TopDocs::with_limit(10))?;

for (_score, doc_address) in top_docs {
    let doc = searcher.doc(doc_address)?;
    let name = doc.get_first(symbol_name).unwrap().as_str().unwrap();
    let file = doc.get_first(file_path).unwrap().as_str().unwrap();
    println!("Found: {} in {}", name, file);
}
```

Fuzzy Search:
```rust
use tantivy::query::FuzzyTermQuery;

let term = Term::from_field_text(symbol_name, "functon"); // typo
let fuzzy_query = FuzzyTermQuery::new(term, 2, true); // 2 edits, transposition
let top_docs = searcher.search(&fuzzy_query, &TopDocs::with_limit(10))?;
```

Key Tantivy Concepts:
- Schema: Defines document structure and field types
- Index: Storage and retrieval system
- IndexWriter: Adds/updates documents (single writer)
- Searcher: Reads and queries index (multiple readers)
- Document: Unit of indexing (set of field values)
- Query: Search pattern (term, phrase, fuzzy, boolean)

Performance Tips:
- Batch document adds before commit
- Use appropriate heap size for IndexWriter
- Commit periodically, not per-document
- Use ReloadPolicy for reader freshness
- Consider using multiple segments

3. STACK-GRAPHS INTEGRATION
================================================================================

Basic Concepts:
- StackGraph: Global graph of all symbols in project
- File: Represents a source file in the graph
- Node: Represents a symbol (definition, reference, scope)
- Edge: Connects nodes (precedence, defining scope)
- Path: Sequence of edges connecting reference to definition

Initial Setup:
```rust
use stack_graphs::graph::StackGraph;
use stack_graphs::storage::FileEntry;

let mut graph = StackGraph::new();

// Add a file to the graph
let file_name = "src/main.rs";
let file = graph.add_file(file_name)?;
```

Adding Nodes:
```rust
// Add a definition node
let def_node = graph.add_symbol_definition(
    file,
    "my_function",  // symbol name
);

// Add a reference node
let ref_node = graph.add_symbol_reference(
    file,
    "my_function",  // symbol being referenced
);

// Add a scope node (module, function, block)
let scope_node = graph.add_scope(file);
```

Connecting Nodes:
```rust
// Connect definition to its containing scope
graph.add_edge(scope_node, def_node);

// Connect reference to search path
graph.add_edge(ref_node, scope_node);
```

Resolution:
```rust
use stack_graphs::stitching::ForwardPartialPathStitcher;

// Create a path stitcher
let mut stitcher = ForwardPartialPathStitcher::new(&graph);

// Find definition for a reference
let paths = stitcher.find_all_paths(ref_node);

for path in paths {
    if let Some(def_node) = path.end_node {
        // Found the definition!
        let def_file = graph.file_for_node(def_node);
        let def_symbol = graph.symbol_for_node(def_node);
        println!("References {} defined in {}", def_symbol, def_file);
    }
}
```

Handling Imports:
```rust
// For "use std::collections::HashMap"
// 1. Add reference node for HashMap
// 2. Add path through module structure: std -> collections -> HashMap
// 3. Connect to actual definition in std library

let import_ref = graph.add_symbol_reference(file, "HashMap");
let std_scope = graph.add_scope(graph.stdlib_file());
let collections_scope = graph.add_scope(graph.stdlib_file());
// ... connect the path
```

Key Stack-graphs Concepts:
- Definition: Where a symbol is declared
- Reference: Where a symbol is used
- Scope: Lexical scope (module, function, block)
- Push Symbol: Adds to the symbol stack
- Pop Symbol: Removes from stack, must match
- Jump to Scope: Transitions between scopes

Advanced Patterns:
```rust
// Handle visibility (pub vs private)
let visibility = if is_public {
    Visibility::Public
} else {
    Visibility::Private
};
graph.set_node_visibility(def_node, visibility);

// Handle namespaces (modules)
let module_scope = graph.add_scope(file);
graph.add_symbol_definition(module_scope, "module_name");

// Connect child items to module scope
graph.add_edge(module_scope, child_def_node);
```

Performance Tips:
- Build graph incrementally per file
- Cache file graphs for unchanged files
- Use partial path stitching for queries
- Consider memory usage with very large graphs
- Parallelize graph building per file

4. PUTTING IT ALL TOGETHER
================================================================================

Complete Pipeline:

```rust
struct SemanticIndexer {
    parser: Parser,
    tantivy_index: Index,
    stack_graph: StackGraph,
}

impl SemanticIndexer {
    pub fn index_project(&mut self, root: &Path) -> Result<()> {
        // 1. Crawl files
        let files = self.crawl_files(root)?;

        // 2. Parse and extract in parallel
        let symbols: Vec<_> = files.par_iter()
            .filter_map(|file| self.parse_file(file).ok())
            .flatten()
            .collect();

        // 3. Index in Tantivy
        let mut writer = self.tantivy_index.writer(50_000_000)?;
        for symbol in &symbols {
            writer.add_document(self.symbol_to_doc(symbol)?)?;
        }
        writer.commit()?;

        // 4. Build Stack-graph
        for file in files {
            let file_node = self.stack_graph.add_file(&file)?;
            self.build_file_graph(file_node, &file)?;
        }

        Ok(())
    }

    fn parse_file(&mut self, path: &Path) -> Result<Vec<Symbol>> {
        let content = std::fs::read_to_string(path)?;
        let tree = self.parser.parse(&content, None).unwrap();

        // Extract symbols using Tree-sitter
        let symbols = self.extract_symbols(&tree, &content, path)?;
        Ok(symbols)
    }

    fn build_file_graph(&mut self, file: FileHandle, path: &Path) -> Result<()> {
        // Parse file
        let symbols = self.parse_file(path)?;

        // Add definitions and references to stack-graph
        for symbol in symbols {
            match symbol.kind {
                SymbolKind::Definition => {
                    let node = self.stack_graph.add_symbol_definition(file, &symbol.name);
                    // Connect to scope...
                }
                SymbolKind::Reference => {
                    let node = self.stack_graph.add_symbol_reference(file, &symbol.name);
                    // Add to resolution path...
                }
            }
        }

        Ok(())
    }
}
```

Query Flow:

```rust
// User searches for "handle_events"
fn search_symbol(&self, query: &str) -> Result<Vec<SearchResult>> {
    // 1. Tantivy finds matching symbols
    let tantivy_results = self.search_tantivy(query)?;

    let mut results = Vec::new();
    for result in tantivy_results {
        // 2. For each result, use stack-graphs to find:
        //    - Definition location
        //    - All references
        //    - Type information
        let def = self.find_definition(&result.name)?;
        let refs = self.find_references(&result.name)?;

        results.push(SearchResult {
            name: result.name,
            definition: def,
            references: refs,
            // ... other metadata
        });
    }

    Ok(results)
}
```

5. DATA STRUCTURES
================================================================================

Core Types:

```rust
#[derive(Debug, Clone)]
pub struct Symbol {
    pub name: String,
    pub kind: SymbolKind,
    pub location: CodeLocation,
    pub visibility: Visibility,
    pub signature: Option<String>,
    pub doc_comment: Option<String>,
    pub fqn: String, // Fully qualified name: "module::struct::method"
}

#[derive(Debug, Clone, Copy)]
pub enum SymbolKind {
    Function,
    Struct,
    Enum,
    Trait,
    Impl,
    Constant,
    Variable,
    Module,
    TypeAlias,
    Method,
}

#[derive(Debug, Clone)]
pub struct CodeLocation {
    pub file: PathBuf,
    pub line: usize,
    pub column: usize,
    pub byte_offset: usize,
}

#[derive(Debug, Clone, Copy)]
pub enum Visibility {
    Public,
    PublicCrate,
    Private,
}

#[derive(Debug)]
pub struct SearchResult {
    pub symbol: Symbol,
    pub definition: CodeLocation,
    pub references: Vec<CodeLocation>,
    pub score: f32,
}
```

6. ERROR HANDLING
================================================================================

Custom Error Types:

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum IndexerError {
    #[error("Failed to parse file: {0}")]
    ParseError(String),

    #[error("Tree-sitter error: {0}")]
    TreeSitterError(String),

    #[error("Tantivy error: {0}")]
    TantivyError(#[from] tantivy::TantivyError),

    #[error("Stack-graphs error: {0}")]
    StackGraphsError(String),

    #[error("IO error: {0}")]
    IoError(#[from] std::io::Error),

    #[error("Index not found")]
    IndexNotFound,
}

pub type Result<T> = std::result::Result<T, IndexerError>;
```
