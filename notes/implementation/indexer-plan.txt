================================================================================
SEMANTIC CODE INDEXER - IMPLEMENTATION PLAN
================================================================================

Project Goal: Build a high-performance semantic code indexer in Rust that provides
intelligent code search and navigation capabilities using Tree-sitter, Tantivy,
and Stack-graphs.

References:
- Tree-sitter: https://tree-sitter.github.io/tree-sitter
- Tree-sitter Rust docs: https://docs.rs/tree-sitter/0.26.3
- Tantivy: https://docs.rs/tantivy/latest/tantivy/
- Stack-graphs: https://github.com/github/stack-graphs/tree/main/stack-graphs
- Stack-graphs docs: https://docs.rs/stack-graphs/0.14.1

□ 3.2 Define Search Schema
  - [ ] Create src/search/tantivy.rs
  - [ ] Define Tantivy schema with fields:
        - symbol_name: TEXT (tokenized, stored)
        - symbol_kind: STRING (not tokenized, stored)
        - file_path: STRING (stored)
        - line_number: U64 (stored, indexed)
        - column_number: U64 (stored, indexed)
        - signature: TEXT (tokenized, stored, optional)
        - doc_comment: TEXT (tokenized, stored, optional)
        - visibility: STRING (stored)
        - full_qualified_name: TEXT (stored) # e.g., "mod::struct::method"
  - [ ] Create index directory structure (.ch-cli-index/)
  - [ ] Test: Create index and verify schema

□ 3.3 Implement Index Writer

IMPLEMENTATION STRATEGY
================================================================================

Development Approach:
1. Build in phases - complete one milestone before moving to next
2. Write tests alongside implementation
3. Use existing ch-cli UI as the interface
4. Start with Rust-only support, expand later
5. Keep performance in mind from day one
6. Document as you go

Key Decisions to Make Early:
- [ ] Where to store index? (.ch-cli-index/ in project root)
- [ ] How to handle multi-workspace projects?
- [ ] Should indexing be automatic or manual?
- [ ] How to display search results in TUI?

Tools & Libraries Summary:
✓ tree-sitter + language parsers - AST parsing
✓ tantivy - Full-text search engine
✓ stack-graphs - Semantic resolution
✓ rayon - Parallel processing
✓ ignore - .gitignore support
✓ notify - File watching (optional)
✓ tracing - Logging

================================================================================
SUCCESS METRICS
================================================================================

The indexer is successful when:
✓ Can index 10,000+ file project in < 30 seconds
✓ Search returns results in < 100ms
✓ Correctly resolves 95%+ of symbol references
✓ Handles incremental updates efficiently
✓ Gracefully handles parse errors
✓ Memory usage stays reasonable (< 500MB for large projects)
