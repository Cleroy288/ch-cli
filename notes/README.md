# Development Notes

This folder contains ongoing development notes, exploration, and implementation planning. Unlike the `doc/` folder which documents completed features, this folder captures work-in-progress, architectural decisions, and technical exploration.

## Folder Structure

### `development/`
Historical records and high-level development information:
- `timeline.md` - Development timeline and milestones
- `summary.md` - Summary of implementations
- `refactoring.md` - Ongoing refactoring plans and work

### `implementation/`
Technical notes on specific implementations:
- `indexer-notes.md` - Detailed notes on the indexer implementation
- Project overview and architectural notes

### Root Files
- `INDEX.md` - Index of notes and references

## Purpose

Use this folder to:
- Document architectural decisions and reasoning
- Track work-in-progress on new features
- Record exploration and experimentation
- Keep implementation details before they're finalized
- Plan refactoring and improvements

Once a feature is complete and stable, move its documentation to the `doc/` folder.

## Distinction from doc/

| doc/ | notes/ |
|------|--------|
| Completed, stable features | Work-in-progress |
| User and developer guides | Implementation details |
| Polished documentation | Raw notes and exploration |
| End-user focused | Developer focused |
| Fixed and reviewed | Dynamic and changing |
