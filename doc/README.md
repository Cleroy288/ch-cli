## Project Overview

**rustean** is a semantic code indexer and TUI assistant built with Rust and Ratatui.

### Key Features
- 🔍 Fast semantic code indexing for Rust projects
- 🎨 Beautiful terminal UI with ASCII art and interactive components
- 📁 File and folder picker with fuzzy search
- 💬 Message parsing and conversation history
- 🎯 Clean, modular architecture
